# 风格指南模板（style_guide_template.md）

> S3 的产物 `state/style_guide.md` 按本模板填写。六个字段**必须全部覆盖**；
> 每个字段给 1–3 句结论 + 至少一个从抽样里摘出的示例。无法判断的字段写「未观察到明显特征」，
> 不要留空。

## 1. 体裁（Genre）

判断文本属于哪种体裁，并说明对翻译的影响。

- 示例：「轻小说 / 学术论文 / 传记 / 商业文档 / 对话体剧本」
- 填写示例：「本作是轻小说，偏青春文学。翻译需保持叙事流畅与轻快语气，不追求书面文言。」

## 2. 语气（Tone）

判断整体语气：正式/口语、克制/夸张、冷峻/温情，以及是否有反讽、粗俗、露骨内容。

- 填写示例：「整体克制、内敛，战斗场景略紧张；对话偏口语。露骨/粗俗表述照译不淡化。」

## 3. 叙事人称（Narrative Person）

判断叙述视角：第一人称 / 第二人称 / 第三人称，是否混用。

- 填写示例：「第一人称（'我'），内心独白较多；配角对话用第三人称指代。」

## 4. 句式节奏（Sentence Rhythm）

判断句子长短分布、段落节奏，以及是否有重复句式、排比。

- 填写示例：「短句为主，段落不长；战斗段落句子明显变短。保留原文换行与空行节奏。」

## 5. 语域（Register）

判断用词层级：书面语/口语、术语密度、方言、时代感。

- 填写示例：「现代日语口语 + 少量设定术语（魔法、组织名）。术语按术语表统一译法；方言用普通话口语对应，不强行方言化。」

## 6. 对话风格（Dialogue Style）

判断人物说话方式：称呼方式、敬语/平语、口头禅、语气词，是否因人而异。

- 填写示例：「主角对前辈用敬语、对后辈用平语；角色 A 有口癖'……的说'。称呼（先輩/お嬢様等）按术语表锁定词条执行，不加戏。」
