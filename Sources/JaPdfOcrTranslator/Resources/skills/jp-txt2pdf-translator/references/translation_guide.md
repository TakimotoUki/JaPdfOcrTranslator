# 翻译细则（translation_guide.md）

配合 `jp-txt2pdf-translator` **九阶段流水线**使用（S0–S8，见 `SKILL.md`）。
本文档覆盖：OCR 清洗、格式保真、术语类型与匹配、预抽/回抽判据、标点规范、段落对齐、翻译原则。

---

## 一、OCR 文本清洗（S1 前）

- 合并被拆断的句子：OCR 常把一句拆成多行，按语义合并回完整句。
- 折叠多余空行：连续空行压成段落间单个空行；保留「空行即段落分隔」的语义。
- 粘连文本：相邻两段被并到一行时，按句号/换行符拆回。
- **原样保留**：序号、标记符、占位符（`{name}`、`%s`、`<tag>`）、换行符、转义符、代码调用过程。
- 诗歌/代码/法条等「换行即语义」内容，用 ` ``` ` 或 `~~~` 围栏包裹。

## 二、格式保真清单

- 编号列表、括号标注、脚注标记、占位符、模板变量：逐字保留。
- 引文出处如 `(清水1986:6,7)`、`(伊東1988:375)` 原样保留。
- 版本号、小数、文件路径、URL、邮箱：不得被标点规则误改（`normalize_punct.py` 已保护，翻译时也勿动）。
- 代码围栏（` ``` ` / `~~~`）内的行：**一个字符都不改**。

## 三、术语类型与 `SOURCE_ONLY_TYPES`（对应 §3.6）

术语 `type` 值域（未知一律归 `其他`）：

`人物 | 地名 | 组织 | 术语 | 招式 | 物品 | 称谓 | 敬称 | 口癖 | 固定表达 | 其他`

**`SOURCE_ONLY_TYPES = {称谓, 敬称, 口癖, 固定表达}`** —— 这四类**只按 `source` 匹配，忽略 `aliases`**。
含义：`称谓/敬称/口癖/固定表达` 的 alias 通常是带语气的裸名变体（如「静ちゃん」），
若允许按 alias 注入会污染普通称呼的译法；因此只认 source 本身。

应当入表：人名、地名、组织名、作品内专有术语、招式名、物品名、设定名；
同一实体的称呼变体（昵称／敬称／职称／亲属称呼／外号）应作为**独立条目**而非仅放 aliases；
需全书统一的口癖、咒语、标语、固定台词。
不应入表：普通寒暄、通用词汇、一次性修辞、普通语气词。

## 四、预抽 / 回抽判据（S4 五步的①④）

- **预抽（`--phase pre`）**：翻译第 N 块**之前**，对该块**源文**做术语抽取并写库。
  判据：新专名 → `inserted`；与库中同 source 同 target → `unchanged`；同 source 不同 target →
  `conflict`（保留现值）；对锁定词条给出不同译名 → `rejected_by_lock`。
  **即使一条新词都没有，也必须以 `{"terms":[]}` 调用一次** —— 这是 F33-02 合规的唯一证据。
- **回抽（`--phase post`）**：翻译完成后，用「原文 + 译文」校准**实际采用**的写法填 `target`，
  不要凭空创造译名。
- 时序铁律：`glossary_pre_extract{chunk:N}` 必须由 `upsert --phase pre --chunk N` 产生，
  且 seq 早于同块的 `chunk_translated`；`state_tool.py verify --check pre-extract-order` 逐块验收。

## 五、标点规范（对齐 `normalize_punct.py`，F33-13）

译文统一为简体中文大陆全角标点：

| 原文 | 规范化后 |
|---|---|
| `「` `」` | `“` `”`（中文双引号） |
| `『` `』` | `‘` `’`（中文单引号） |
| `,` `.` `!` `?` `:` `;` | `，` `。` `！` `？` `：` `；`（数字/版本号/路径内不动） |
| `...`（3 个及以上） | `……` |
| `--`（2 个及以上） | `——` |

两处保护：代码围栏内整行不改；行内 URL/邮箱/行内代码/版本号/路径挖占位符后回填。
`normalize_punct.py --dry-run` 可先看统计再落盘。

## 六、段落对齐要求（S6，对应 §3.8）

- **译文段落数必须与原文一致**：原文 5 段，译文就必须 5 段；不得合并、不得拆分。
- `check_alignment.py` 判 error 的条件：`|段落数差| ≥ 2`，或 `|差| / 原文段数 ≥ 15%`。
- 字符数比（译文/原文）需落在 `[0.55, 1.70]`，越界记为 `ratio_out_of_range`（warn 级）。
- 出现 error 时按报告 `error_chunks` 修正对应译块后重跑，直到退 0。

## 七、翻译原则（S4 ③）

1. 忠实准确、尊重原文：不增删、不篡改、不雅化改写；艺术作品中的直白/粗俗内容照译不淡化。
2. 通俗易懂：现代普通话，避免文言与晦涩长难句。
3. 仅替换日语自然语言；特殊格式原样保留。
4. 保持原作的语气、节奏与文体（以 `state/style_guide.md` 为准）。

## 八、跨块截断句（S5）

- `check_boundaries.py` 标出「上块结尾未以句末符结束」的可疑衔接点。
- 确属一句被拆开 → 合并上下块续句重译，使语义连贯；每修一处留 `boundary_fixed` 事件。
- 仅是正常段落/短语边界 → 无需改动。

## 九、全篇复核与交付（S8）

- 合并后通读，查错译、漏译、难解处、译名一致性、段落衔接、顺畅度、格式保真；发现问题就地修正
  对应 `chunk_NNN_zh.txt` 并重跑 `merge.py`。
- PDF：宋体（STSong-Light）；章节标题居中加粗；正文两端对齐、首行缩进；页脚页码；可选封面；
  对照模式 `--bilingual --original` 每段先排日文原文（灰字）再排中文译文。
